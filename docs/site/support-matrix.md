## Important nuances

### Zero downtime is per Service kind

Yoho does not promise blanket zero downtime for every container in an App:

- **Proxied Services** (`x-yoho.proxy`) switch without downtime: new containers start alongside old ones, pass their healthcheck, and kamal-proxy drains existing connections before removing old containers.
- **Workers / non-proxied stateless Services** restart **stop-first** on the compose runtime, without overlapping copies. On Swarm, they use rolling updates that default to **start-first**, so old and new tasks can overlap.
- **Stateful Services** restart **stop-first** on both runtimes. Yoho never overlaps two copies of a Stateful Service.
- **Upgrading the shared Proxy** (`yoho proxy upgrade` or a Proxy image/config change during deploy) recreates `yoho-proxy` and causes roughly a one-second interruption for all Apps on that Server ([Upgrading the Proxy](zero-downtime.md#upgrading-the-proxy)).

### Image transport

With the default `transport.mode: auto`, Yoho ships images over SSH without requiring a container registry:

- **Layer-diff push (`docker pussh`)** is used only when both the local `docker pussh` plugin and the Server's containerd image store are present.
- **Full archive (`docker save | docker load`)** is the automatic fallback whenever either requirement is missing. `builder.direct` remote builds and Apple `container` builds always ship full archives ([Builds & image transport](builds.md)).

### What the Gate enforces — and what it does not

The Gate (`access: scoped`) provides **scoped authorization per App Destination** (fixed verbs, no shell, no Docker socket, isolated Proxy network, and no access to other Apps on the Server). It is **not** a mandatory human-approval barrier:

- `yoho deploy` and `yoho apply --auto-approve` skip interactive confirmation prompts.
- While Yoho never reveals secret values to a Member, any code a Member deploys runs with that App's secrets mounted and can read or exfiltrate them ([Team access](team-access.md#secrets)). Grant `deploy` only to teammates or CI jobs you trust with that App's secrets.
